# AntiDupe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Paper 26.3 plugin that gives unstackable items a hidden serial, removes proven duplicate copies into a restorable quarantine, guards the shulker and relog dupes, and punishes only the player who made the copy.

**Architecture:** Two Gradle modules. `core` is plain Java with no Paper imports: registry, duplicate decision, punishment ladder, SQLite storage. It is fully unit-tested. `plugin` depends on `core` and on `paper-api`; it turns game events into calls into `core` and acts on the answers.

**Tech Stack:** Java (core: release 21; plugin: release 25), Gradle 8.14 Kotlin DSL, JUnit 5.11, sqlite-jdbc 3.47.0.0 (Paper ships it at runtime, so it is `compileOnly` in `plugin`), paper-api 26.3.

**Spec:** `docs/superpowers/specs/2026-11-10-antidupe-design.md`

## Global Constraints

- Package root: `dev.novablaze.antidupe` (`.core` for core, `.plugin` for the plugin).
- Plugin name `AntiDupe`, `api-version: '26.3'` (fallback: newest published 26.x, per spec section 11).
- Core has zero imports from `org.bukkit`, `io.papermc` or `net.kyori`.
- No server internals (NMS): public Paper API only.
- No world scanning on a timer. Checks only on item movement, container open, join and quit.
- Never treat an unloaded location as proof of a duplicate.
- Defaults: ladder WARN, KICK, BAN 2 hours; offence expiry 30 days; quarantine retention 30 days.
- Offences and bans keyed by lower-cased player name.
- Permissions: `antidupe.admin`, `antidupe.alerts`, `antidupe.bypass`.
- SQLite writes happen off the main server thread.
- AuthMe is a soft dependency.

## Review Focus

1. **Moving an item inside one's own inventory** (hotbar to backpack, armour slot): same holder, so it must never be flagged. Tested in Task 2.
2. **The old holder is offline or in an unloaded chunk**: must defer, never flag. Tested in Task 2.
3. **Two copies inside a single inventory** (both in the same chest after a dupe): must be caught even though the holder is the same. Tested in Task 2.
4. **An innocent player holding a copy they were given**: copy removed, no offence recorded. Tested in Task 2 (culprit is null when the sighting has no actor) and Task 3.
5. **A player who duped once, 31 days ago, dupes again**: counts as a 1st offence, so only a warning. Tested in Task 3.

### Task 2: Registry and duplicate detector

**Files:**
- Create: `core/src/main/java/dev/novablaze/antidupe/core/Registry.java`, `HolderProbe.java`, `Sighting.java`, `Verdict.java`, `DupeDetector.java`
- Test: `core/src/test/java/dev/novablaze/antidupe/core/DupeDetectorTest.java`, `RegistryTest.java`

**Interfaces:**
- Consumes: `Holder`.
- Produces:
  - `Registry`: `Optional<Holder> lastSeen(String serial)`, `void record(String serial, Holder at)`, `void forget(String serial)`, `Map<String, Holder> snapshot()`, `void loadAll(Map<String, Holder>)`. Thread-safe (`ConcurrentHashMap`).
  - `interface HolderProbe { boolean isLoaded(Holder h); boolean holds(Holder h, String serial); }` — implemented by the plugin.
  - `record Sighting(String serial, Holder at, String actor)` — `actor` is the lower-cased name of the player whose action produced this sighting, or `null`.
  - `sealed interface Verdict` with records `New()`, `Same()`, `Moved(Holder from)`, `Deferred(Holder from)`, `Duplicate(Holder original, String culprit)`.
  - `DupeDetector(Registry, HolderProbe)`: `Verdict check(Sighting s)` and `List<Integer> internalDuplicates(List<String> serialsBySlot)` (slot indexes of the 2nd and later occurrence of each serial; `null` entries ignored).

Decision rules for `check`, in order:
1. No record: record it, `New`.
2. Record equals `s.at()`: `Same`.
3. Old holder not loaded: keep the old record, `Deferred(old)`.
4. Old holder still holds the serial: keep the old record, `Duplicate(old, s.actor())`.
5. Otherwise: record the new holder, `Moved(old)`.

- [ ] **Step 1:** Write `DupeDetectorTest` with a fake probe:
  - `first_sighting_is_new` → `New`, registry now has it.
  - `moving_within_same_holder_is_same` → `Same` (Review Focus 1).
  - `old_holder_unloaded_defers_and_keeps_record` → `Deferred`, registry still old (Review Focus 2).
  - `old_holder_still_has_it_is_duplicate_with_actor_as_culprit` → `Duplicate(old, "steve")`.
  - `duplicate_without_actor_has_null_culprit` → culprit `null` (Review Focus 4).
  - `old_holder_no_longer_has_it_is_moved` → `Moved`, registry updated.
  - `internal_duplicates_returns_later_slots` → for `["a", null, "b", "a", "a"]` returns `[3, 4]` (Review Focus 3).
  - `RegistryTest`: `snapshot`/`loadAll` round-trip; `forget` removes.
- [ ] **Step 2:** Run `gradle :core:test`. Expected: FAIL.
- [ ] **Step 3:** Implement the classes.
- [ ] **Step 4:** Run `gradle :core:test`. Expected: PASS.
- [ ] **Step 5:** Commit `feat(core): registry and verify-before-delete detector`.

- Test: `core/src/test/java/dev/novablaze/antidupe/core/StorageTest.java`

**Interfaces:**
- Consumes: `Holder`, `OffenceStore`.
- Produces:
  - `Storage(java.nio.file.Path dbFile)` implements `OffenceStore`, `BanStore`, `AutoCloseable`. Creates tables `registry(serial PK, holder)`, `quarantine(id PK AUTOINCREMENT, serial, item BLOB, holder, culprit, reason, at)`, `offences(name, at)`, `bans(name PK, until)`.
  - Registry: `Map<String, Holder> loadRegistry()`, `void saveRegistry(Map<String, Holder>)` (replace all, one transaction).

### Task 6: Listeners, probe and enforcement

**Files:**
- Create: `plugin/.../PaperHolderProbe.java`, `Enforcer.java`, `listeners/InventoryListener.java`, `listeners/ItemEntityListener.java`, `listeners/SessionListener.java`

**Interfaces:**
- `PaperHolderProbe implements HolderProbe`: `isLoaded` = player online / chunk loaded / entity valid / for `IN_SHULKER` the box's holder is loaded; `holds` scans only that one inventory (for `IN_SHULKER`, the box item's `BlockStateMeta` contents).
- `Enforcer.handle(Verdict, ItemStack copy, Consumer<ItemStack> remove)`: on `Duplicate` quarantine the bytes, run `remove`, alert `antidupe.alerts` holders; if `culprit` is non-null and not `antidupe.bypass`, call `ladder.punish` and apply `Warn` (message), `Kick`, `Ban` (store in `BanStore`, kick). If culprit is null, tell the holder the item was a duplicate.
- Sightings: inventory open (all covered items, plus `internalDuplicates`), click/drag result, pickup, drop (holder `GROUND`), join (inventory and ender chest, actor = joiner), quit (save).
- `AsyncPlayerPreLoginEvent`: refuse if `bannedUntil` is present, showing the remaining time.

- [ ] Steps: on the test server, a copy made with `/give` of an NBT-identical item is caught and quarantined; moving it around the inventory, dropping and picking up are not flagged; the ladder goes warn, kick, ban. Commit.
